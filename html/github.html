🚀 ابدأ بسرعة

لتشغيل المشروع محلياً على جهازك، اتبع الخطوات البسيطة دي:

Terminal
# 1. استنسخ المشروع
git clone https://github.com/HazemYT55/yawmi.git
# 2. ادخل للمجلد
cd yawmi
# 3. شغّل سيرفر محلي
python -m http.server 8000
# 4. افتح المتصفح على
# http://localhost:8000
Alternative (Python API Server)
# لتشغيل Flask API Server
pip install flask flask-cors
cd py
python api.py
# السيرفر على http://localhost:5000

🤝 كيف تساهم؟

المشروع مفتوح للمساهمات! سواء كنت مطور، مصمم، أو حتى عندك اقتراح — كل مساهمة مرحّب بها.

  1. 1. Fork المشروع

    اضغط زر "Fork" في أعلى صفحة GitHub لإنشاء نسخة خاصة بك

  2. 2. استنسخ نسختك

    git clone https://github.com/YOUR-USERNAME/yawmi.git

  3. 3. أنشئ فرع جديد

    git checkout -b feature/amazing-feature

  4. 4. اعمل التعديلات و Commit

    git commit -m 'أضفت ميزة رائعة'

  5. 5. ارفع الفرع

    git push origin feature/amazing-feature

  6. 6. افتح Pull Request

    ارجع لـ GitHub وافتح PR — هنراجعه في أقرب وقت

Git Workflow
# خطوات Git الكاملة
git checkout -b feature/amazing-feature
git add .
git commit -m "إضافة ميزة جديدة"
git push origin feature/amazing-feature
