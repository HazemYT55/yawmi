توثيق API

كل الـ endpoints المتاحة في تطبيق يومي — Flask REST API

💡
عن الـ API
تطبيق يومي بيوفّر Flask REST API كامل يقدر يشتغل بشكل مستقل أو بالتوازي مع الواجهة. كل الردود بصيغة JSON، وموحّدة، ومش محتاجة توثيق.
🌐 Base URL
http://localhost:5000/api
❤️ Health 👤 User 📅 Schedule ⚽ Workouts 📖 Quran 🌤️ Weather 🏆 Badges 🎁 Rewards 📊 Stats 💾 Backup

❤️ Health Check 1 endpoint

فحص حالة السيرفر — يُستخدم عادةً من قِبل أدوات المراقبة.

GET /health
يرجع حالة السيرفر والإصدار.
Response
{ "success": true, "data": { "status": "healthy", "version": "4.0.0", "surahs_loaded": 114 } }
200 OK

👤 User API 6 endpoints

إدارة بيانات المستخدم والإعدادات والإحصائيات.

GET /api/user
جلب بيانات المستخدم.
POST /api/user
تحديث بيانات المستخدم (name, age, gender, height, weight).
Request Body
{ "name": "حازم", "age": 13, "gender": "male" }
GET /api/user/settings
جلب الإعدادات (darkMode, sound, weekend...).
PUT /api/user/settings
تحديث الإعدادات.
GET /api/user/stats
جلب الإحصائيات (نقاط، Streak، مهام...).
POST /api/user/stats
تحديث الإحصائيات (زيادة نقاط/مهام/تمرين).

📅 Schedule API 4 endpoints

إدارة الجدول اليومي — الحفظ، والتوليد، والتعديل.

GET /api/schedule
جلب الجدول الحالي.
POST /api/schedule
حفظ جدول جديد (استبدال الحالي).
POST /api/schedule/generate
توليد جدول تلقائياً بناءً على المدخلات.
Request Body
{ "wakeUp": "06:00", "schoolStart": "07:00", "schoolEnd": "14:30", "trainingTime": "17:00", "trainingDuration": 90, "weekend": false, "homeworks": [], "quran": { "new": 1, "recent": 2, "old": 1 } }
POST /api/schedule/adjust
تعديل طارئ للجدول (إعادة ترتيب المهام المتبقية).

⚽ Workouts API 4 endpoints

18 تمرين رياضي في 3 فئات: رشاقة، قوة، وتحمل.

GET /api/workouts
جلب كل التمارين.
GET /api/workouts/<category>
تمارين فئة معينة. category: agility | strength | endurance
GET /api/workouts/<category>/<id>
تفاصيل تمرين معين.
POST /api/workouts/routine
توليد روتين مخصص حسب الوقت والمستوى.

📖 Quran API 8 endpoints

القرآن الكريم — 114 سورة، 10 قراء، مع خطط الحفظ.

GET /api/quran/surahs
قائمة كل السور (114 سورة).
GET /api/quran/surah/<id>
تفاصيل سورة (id من 1 إلى 114).
GET /api/quran/ayah/<surah>/<ayah>
آية محددة.
GET /api/quran/audio/<id>
رابط صوت سورة كاملة. Query: ?reciter=alafasy
GET /api/quran/reciters
قائمة القراء المتاحين (10 قراء).
POST /api/quran/plan
توليد خطة حفظ قرآنية.
GET /api/quran/progress
جلب تقدم الحفظ.
POST /api/quran/progress
تحديث تقدم الحفظ.

🌤️ Weather API 2 endpoints

حالة الطقس + نصائح رياضية حسب الجو.

GET /api/weather
جلب الطقس. Query: ?lat=24.7&lon=46.7
POST /api/weather/advice
نصيحة رياضية حسب الحرارة والرمز.

🏆 Badges API 2 endpoints

27 شارة في 5 فئات — مع فحص الجديد.

GET /api/badges
كل الشارات مع حالة كل واحدة.
POST /api/badges/check
فحص الشارات الجديدة المكتسبة.

🎁 Rewards API 4 endpoints

المكافآت الأسرية — إضافة، حذف، واستبدال.

GET /api/rewards
جلب كل المكافآت مع نسبة التقدم.
POST /api/rewards
إضافة مكافأة جديدة.
DELETE /api/rewards/<id>
حذف مكافأة.
POST /api/rewards/<id>/claim
استبدال مكافأة (يخصم النقاط).

📊 Stats API 3 endpoints

إحصائيات أسبوعية وشهرية + تصدير.

GET /api/stats/weekly
إحصائيات آخر 7 أيام.
GET /api/stats/monthly
إحصائيات آخر 30 يوم.
GET /api/stats/export
تصدير كل الإحصائيات.

💾 Backup API 3 endpoints

النسخ الاحتياطي والاسترجاع.

GET /api/backup
إنشاء نسخة احتياطية جديدة.
GET /api/backup/list
قائمة النسخ الاحتياطية المتاحة.
POST /api/restore
استرجاع نسخة احتياطية.
