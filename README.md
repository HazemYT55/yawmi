# ⚽ يومي

تطبيق لتوليد جدول يومي متوازن للطالب الرياضي (خاصة مدافع كرة القدم).

## المميزات

- 🎯 توليد جدول تلقائي بناءً على وقتك وواجباتك
- 📖 تقسيم الحفظ القرآني (مراجعة قريبة / بعيدة / حفظ جديد)
- ⚽ تمارين رياضية مخصصة للمدافع
- 🍅 Pomodoro Timer مع أصوات هادئة
- ⏱️ مؤقت للتمارين (Stopwatch + مؤقتات جاهزة)
- 😊 تتبع الطاقة والمزاج لتعديل صعوبة اليوم
- 🏖️ Weekend Mode ليوم بدون مدرسة
- 🌤️ حالة الطقس لاقتراح تمارين مناسبة
- 🏆 نظام نقاط وشارات مع Streak
- 💾 يعمل بدون إنترنت

## التشغيل

افتح `index.html` في المتصفح مباشرة.
